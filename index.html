Matteo Backups

A personal backup tool operated by Matteo for his own Google Drive account.

The tool uses rclone on a private computer to upload selected local documents to a Google Drive backup folder. It keeps replaced remote files in a separate version-history folder. This website provides information about the tool; it does not provide sign-in, file upload, or public access to backups.

Google Drive access

The configured Drive permission allows the local tool to list existing backup contents and upload or update backup files. Google authorization happens through Google’s consent screen and a local desktop callback. Authorization tokens are stored on the private computer, not on this website.

This tool is for the owner’s personal use; there is no public registration.
