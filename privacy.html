Privacy — Matteo Backups

Last updated: 15 October 2026.

Matteo Backups uses Google Drive access to maintain the account owner’s personal backups. The local backup tool processes the selected local file contents and file metadata, sends selected files to the owner’s Google Drive, and reads remote metadata to decide which files need updating. Replaced remote files may be retained as earlier versions.

Access and refresh tokens are held in a private local configuration file. They are not included in these web pages. Backups are not made publicly available by this website. The tool is not configured to sell backup data or use it for advertising.

Backup files remain until the owner changes retention or removes them. Revoking access prevents future authorized operations; it does not remove backup files already stored in Drive. The owner can manage those files directly in Google Drive.

Google processes information according to its own policies. These static pages include no analytics scripts, forms or sign-in handler; the hosting provider may process ordinary web request logs.

Access can be revoked through Google Account connections. For questions, use the support contact displayed on the Google consent screen.
